# Login and reset password

::: info
Use this when your account has already been approved and you need to sign in.
:::

## Who can do this

Only **Active** users with an assigned role can log in.

## Login steps

1. Open the website.
2. Select **Login**.
3. Enter your email address and password.
4. Select **Login**.

## If login does not work

- **Awaiting admin approval** means your account is still Pending.
- **Registration rejected** means an admin did not accept the account.
- **Account archived** means the account was disabled by an admin.
- **Invalid credentials** means the email or password may be wrong.

## Reset password steps

1. On the login page, select **Forgot password?**
2. Enter your email address.
3. Check your email for the reset link.
4. Open the reset link.
5. Enter and confirm your new password.
6. Return to Login and sign in again.

::: tip Before you start
Password reset only works for active accounts. The reset link is time-limited, so use it soon after receiving it.
:::

## Expected result

You should reach the website as a signed-in user and see the options allowed for your role.
