# Roles and permissions

::: info
Use this when you need to know what each account type can do.
:::

## Roles

| Role | What it means |
| --- | --- |
| Admin | Manages users, invite codes, projects, precast elements, documents, and deletion. |
| Editor | Updates projects, precast elements, documents, and confidential files. |
| Client | Views allowed project and element information. |

## Common access rules

- Anyone can view public project listings.
- Signed-in users can open project and element detail pages.
- Project documents require login.
- Confidential documents are visible only to admins and editors.
- Activity history is visible only to admins and editors.
- Creating projects and creating precast elements is admin-only.
- Editing projects, elements, and documents is available to admins and editors.

## How admins change a role

1. Log in as an admin.
2. Open **Admin**.
3. Select **Users**.
4. Find the user.
5. Choose the new role.
6. Confirm the role change.

## Expected result

The user keeps the same account, but their available actions change based on the new role.
