# Manage invite codes

::: info
Use this when you need to let new users register.
:::

## Who can do this

Only admins can create, send, archive, restore, or delete invite codes.

## Create an invite code

1. Log in as an admin.
2. Open **Admin**.
3. Select **Users**.
4. Open the **Invites** tab.
5. Select **Create Invite Code**.
6. Add a label if it helps you remember who the code is for.
7. Choose an expiry.
8. Select **Create**.

## Share an invite

After creating the invite, you can copy the invite link or send it by email from the invite list.

## Archive an invite

Archive a code when it should no longer be used for registration. Archived codes can be restored later.

## Delete an invite

Delete is available for archived invite codes. Use it only when the code record is no longer needed.

## Expected result

The invited user can register with the active invite code, then wait for admin approval.
