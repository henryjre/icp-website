# Admin: approve users

::: info
Use this when a new user has registered and needs access to the platform.
:::

## Who can do this

Only admins can approve, reject, archive, restore, or delete users.

## Steps

1. Log in as an admin.
2. Open **Admin**.
3. Select **Users**.
4. Use the status filter and choose **Pending** if you only want new registrations.
5. Find the user in the list.
6. Choose the role the user should have.
7. Select **Accept**.

## If you should not accept the user

Select **Reject** if the registration should not continue. You can add a short reason so the record is clear.

## What happens after

The user becomes **Active** and can log in with the role you assigned.

## Expected result

The user moves out of Pending status and can access the platform based on their role.
