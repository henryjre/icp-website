# Register with an invite code

Use this when you received an invite code and need to create your account.

## Who can do this

Any invited user can register. You need an active invite code from an ICP-FNET admin.

::: tip Before you start
Keep your invite code ready. If the code is expired, archived, or already used too many times, ask an admin for a new one.
:::

## Steps

1. Open the website.
2. Select **Login**.
3. Select **Register here**.
4. Enter your full name, email address, password, and invite code.
5. Select **Register**.
6. Wait for the success message.

## What happens after

Your account is created as **Pending**. You cannot log in yet. An admin must accept your account and assign your role first.

## Expected result

You should see a message that your registration was submitted and is waiting for admin approval.
