# What this platform is for

::: info
Use this guide when you are new to the ICP-FNET Engineering website and need to understand what work happens inside it.
:::

## Who can use it

Everyone can view the public website pages, such as Home, About Us, Product Overview, Projects, and Contact Us. Signed-in users can open more project details, documents, and element records based on their role.

## What you can do here

The platform helps ICP-FNET keep project information in one place.

- View public project summaries.
- Open detailed project records after login.
- Track precast elements under a project.
- Upload and view plans, test results, and supporting documents.
- Protect confidential documents from client accounts.
- Use QR links to open a precast element record quickly.
- Review recent changes through activity history.

## How the guides are arranged

Start with the task you need to finish:

- New account or login: go to Onboarding.
- Project records: go to Projects.
- Precast items: go to Precast Elements.
- Plans and files: go to Documents and Plans.
- Permissions: go to Account and Access.

## Expected result

You should know which guide to open next and what part of the platform handles your task.
