# Upload or replace the general plan

::: info
Use this when the main project plan needs to be added or updated.
:::

## Who can do this

Admins and editors can upload or replace the general plan.

::: tip Before you start
The general plan must be a PDF, JPG, PNG, WebP, or GIF file. The file must be 10 MB or smaller.
:::

## Upload during project creation

1. Start creating a project.
2. Complete the Details step.
3. On the Documents step, upload the general plan.
4. Continue to Review.
5. Create the project.

## Replace on an existing project

1. Log in as an admin or editor.
2. Open the project.
3. Open the general plan area.
4. Choose the option to replace the plan.
5. Select the new file.
6. Wait for the upload to finish.

## What happens after

The new general plan becomes the plan shown on the project page. If there was an old general plan, it is replaced.

## Expected result

The project shows the latest general plan and records the change in activity history.
