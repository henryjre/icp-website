# Manage project documents

::: info
Use this when a project needs supporting files such as drawings, forms, reports, or other attachments.
:::

## Who can do this

Admins and editors can upload, mark confidential, download, and delete project documents. Clients can view and download only the documents available to them.

::: tip Before you start
Each file must be 10 MB or smaller.
:::

## Upload documents

1. Log in as an admin or editor.
2. Open the project.
3. Open the **Documents** section.
4. Select files or drag them into the upload area.
5. Wait for the upload to finish.

## Mark a document confidential

1. Find the document in the list.
2. Use the confidential option.
3. Confirm the change if asked.

## Delete a document

1. Find the document in the list.
2. Select the delete option.
3. Confirm the deletion.

## Expected result

The project document list shows the latest files. Confidential files are hidden from client accounts.
