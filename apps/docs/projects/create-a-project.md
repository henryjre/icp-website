# Create a project

Use this when a new project needs to be added to the platform.

## Who can do this

Only admins can create projects.

::: tip Before you start
Prepare the project name, client, location, start date, project status, thumbnail image, and general plan file. The general plan must be a PDF or supported image file. Files must be 10 MB or smaller.
:::

## Steps

1. Log in as an admin.
2. Open **Admin**.
3. Select **Create Project**.
4. Fill in the project details.
5. Upload the project thumbnail.
6. Select **Next**.
7. Upload the general plan.
8. Add other project documents if needed.
9. Review the information.
10. Select **Create Project**.

## What happens after

The project is created with a project code like **PRJ0001**. The general plan is saved to the project record.

## Expected result

You should see the success message and a link to open the new project.
