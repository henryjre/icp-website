# View projects

::: info
Use this when you want to browse ICP-FNET projects and open a project record.
:::

## Who can do this

Everyone can view the project list. A signed-in user can open protected project details and documents.

## Steps

1. Open the website.
2. Select **Projects** from the main menu.
3. Browse the project cards.
4. Select a project to open its record.
5. Log in if the website asks you to continue.

## What you can see

A project record may include:

- Project name, location, client, date started, and status.
- General plan.
- Precast elements connected to the project.
- Project documents.
- Activity history, if your role allows it.

## Expected result

You should reach the project record and see the project information allowed for your account.
