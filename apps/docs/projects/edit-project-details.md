# Edit project details

::: info
Use this when project information has changed.
:::

## Who can do this

Admins and editors can edit project details. Only admins can delete a project.

## Steps

1. Log in as an admin or editor.
2. Open **Projects**.
3. Select the project.
4. Open the project details area.
5. Select **Edit**.
6. Update the needed fields, such as name, client, location, status, dates, or thumbnail.
7. Select **Save**.

## Notes

- Use **Completed** when the project is finished.
- Add a completion date when the project status is Completed.
- Replace the thumbnail when the project image needs to change.

## Expected result

The project page shows the updated information, and the change is added to the activity history for admins and editors.
