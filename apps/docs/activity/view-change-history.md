# View change history

::: info
Use this when you need to check what changed on a project or precast element.
:::

## Who can do this

Admins and editors can view activity history. Clients do not see activity history.

## Project history

1. Log in as an admin or editor.
2. Open the project.
3. Open the **Activity** section.
4. Review the recent changes.
5. Use pagination if there are more entries.

## Element history

1. Open the project.
2. Open the element.
3. Open the **Activity** section.
4. Review updates, document uploads, status changes, and other recorded actions.

## What the history shows

Activity history may show:

- Who made the change.
- The user role.
- Date and time.
- What was changed.
- Document uploads or deletions.
- Status updates.

## Expected result

You can confirm the latest project or element changes without asking other users for a manual update.
