# Confidential documents

Use this when a file should be kept away from client accounts.

## Who can do this

Admins and editors can mark documents confidential. Clients cannot see confidential documents.

## What confidential means

A confidential document is still saved in the project or element record, but it is only shown to admins and editors.

Clients cannot:

- See the confidential file in the document list.
- Preview the confidential file.
- Download the confidential file.

## Mark a document confidential

1. Log in as an admin or editor.
2. Open the project or element.
3. Find the document.
4. Turn on the confidential option.

## Remove confidential access

1. Find the document.
2. Turn off the confidential option.

## Expected result

The document visibility changes right away for client accounts.
