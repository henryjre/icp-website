# Download and preview documents

Use this when you need to open or save a project or element file.

## Who can do this

Signed-in users can preview or download documents that their role can access.

## Preview a document

1. Open the project or element.
2. Go to the document section.
3. Select the document preview.
4. Use the viewer controls if available.

## Download a document

1. Open the project or element.
2. Find the document.
3. Select the download option.
4. Save the file when your browser asks.

## If a document is missing

- It may be confidential.
- It may have been deleted.
- You may need to log in.
- Your role may not have access to that file.

## Expected result

The file opens in the viewer or downloads to your device.
