# Scan or share QR links

Use this when a field user needs to open an element record quickly.

## Who can do this

Signed-in users can open element records from QR links. Admins and editors can use the same link for review and updates.

## Share an element link

1. Open the project.
2. Open the element.
3. Find the QR code or share link area.
4. Copy the link or share the QR code.

## Scan a QR code

1. Open the scanner from the element page if available.
2. Allow camera access.
3. Point the camera at an ICP element QR code.
4. Wait for the element page to open.

## If the scan does not work

- Make sure the QR code is for an ICP element.
- Keep the code inside the scanner frame.
- Check that you are signed in.
- Ask an admin or editor to confirm the element still exists.

## Expected result

The correct element page opens without manually searching through the project list.
