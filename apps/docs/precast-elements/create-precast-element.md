# Create a precast element

::: info
Use this when a project needs a new precast element record.
:::

## Who can do this

Only admins can create precast elements.

::: tip Before you start
Prepare the batch number, serial number, element name, location, status, and casting date. The same batch and serial number cannot be used twice in one project.
:::

## Steps

1. Log in as an admin.
2. Open **Projects**.
3. Select the project.
4. Open the **Elements** section.
5. Select **Add Precast Element**.
6. Enter the batch number and serial number.
7. Enter the name, location, status, and casting date.
8. Select **Create Element**.

## What happens after

The element is added to the project and receives its own short link for QR sharing.

## Expected result

The new element appears in the project element list.
