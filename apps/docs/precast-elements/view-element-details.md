# View element details

Use this when you need to check one precast element under a project.

## Who can do this

Signed-in users can view element details. Admins and editors can see more information, including confidential files and activity history.

## Steps

1. Log in.
2. Open **Projects**.
3. Select the project.
4. Open the **Elements** section.
5. Select the precast element.

## What you can see

The element page may show:

- Batch and serial number.
- Element name and location.
- Status, such as Casted or Delivered.
- Casting date.
- Test results.
- Plan documents.
- QR code or share link.
- Activity history, if your role allows it.

## Expected result

You should see the element record and the files available to your account.
