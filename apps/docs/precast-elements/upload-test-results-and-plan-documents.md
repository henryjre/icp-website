# Upload test results and plan documents

::: info
Use this when an element needs test results, drawings, or plan files attached to it.
:::

## Who can do this

Admins and editors can upload, download, mark confidential, and delete element documents. Clients can view only the files available to them.

::: tip Before you start
Each file must be 25 MB or smaller.
:::

## Upload a test result

1. Log in as an admin or editor.
2. Open the project.
3. Open the element.
4. Open the **Test Results** section.
5. Upload the file.
6. Wait for the upload to finish.

## Upload a plan document

1. Open the element.
2. Open the **Plan Docs** section.
3. Upload the plan file.
4. Wait for the upload to finish.

## Mark a file confidential

1. Find the uploaded file.
2. Use the confidential option.
3. Confirm the change if asked.

## Expected result

The element file list shows the uploaded document. Confidential files are visible only to admins and editors.
