# Edit a precast element

::: info
Use this when an element record needs to be corrected or updated.
:::

## Who can do this

Admins and editors can edit precast elements. Only admins can delete an element.

## Steps

1. Log in as an admin or editor.
2. Open the project.
3. Open the **Elements** section.
4. Select the element.
5. Select **Edit**.
6. Update the needed fields.
7. Select **Save**.

## Common updates

- Change the element status from **Casted** to **Delivered**.
- Correct the batch or serial number.
- Update the location.
- Correct the casting date.

## Expected result

The element page shows the updated details, and the change is added to activity history for admins and editors.
